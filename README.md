# Industrial-safety-alert-system-
IoT based Industrial Safety Alert Systems for real time hazard monitoring and emergency alerts

## Project Overview

This project continuously monitors industrial environments using smart sensors. If dangerous conditions such as gas leakage, fire , the system immediately activates alarms and sends alerts.

The system is designed for:
- Factories
- Chemical Industries
- Warehouses
- Manufacturing Units
- Industrial Plants

##  Features

- Real-time monitoring
- Gas leakage detection
- Fire and smoke detection
- Emergency buzzer alerts
- IoT-based remote monitoring
- Low-cost safety solution

## Technologies Used

- Arduino / ESP32
- Embedded Systems
- IoT
- Sensor Networks
- Wireless Communication

##  Components Used

- MQ Gas Sensor
- Flame Sensor
- ESP32 / Arduino UNO
- Buzzer
- Power Supply

##  Working Principle

1. Sensors continuously collect environmental data.
2. The microcontroller processes sensor readings.
3. If hazardous conditions are detected:
   - Buzzer gets activated
   - Warning alert is generated
   - Notification is sent
4. Data can also be monitored remotely using IoT connectivity.

##  System Architecture

Sensors → Microcontroller → Alert System → IoT Cloud → User Notification
